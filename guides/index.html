How to use a spin wheel.

Simple instructions for fair random picks, no-repeat rounds, and saved wheels.

1. Prepare your choices

Open the random name picker or the main Spin the Wheel tool. Paste one option per line into the editor. Blank lines are ignored.

2. Choose your mode

Use normal mode if the same option may appear more than once. Enable No repeat picks for classroom rounds or games where each person should be picked once before resetting.

3. Spin and read the result

Press the blue Spin button. SpinWheelJoy chooses the outcome with a secure random number source before the visual wheel begins moving.

4. Save your wheel

Select Save, name your wheel, and find it in My Wheels later. Data stays on this browser; clearing site storage will remove saved wheels.

5. Share carefully

The public tool link does not contain your custom names. To move a specific wheel between devices, export the JSON file and share it only with someone you trust.

6. Use the right tool

For group assignments, choose Random Team Generator. For number ranges, choose Number Wheel.
