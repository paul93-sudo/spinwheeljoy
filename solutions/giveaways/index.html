Five steps for a transparent casual prize draw

  1. Write the rules first. Decide who is eligible, what each person can win, and what counts as one entry.
  2. Clean the participant list. If two labels are identical, confirm whether they are two legitimate entries or an accidental duplicate.
  3. Pick a reveal. Use a regular name wheel for speed or an animated game if the group wants to watch.
  4. Explain repeat behavior. If multiple winners are planned, decide whether winners remain eligible. Configure no-repeat where the tool supports it.
  5. Record the result. Keep an appropriate record yourself; do not rely on browser storage as a certified audit trail.

Pick a name or pick a prize?

These are different tasks. Use the Random Name Picker to select from eligible entries. Use the Prize Wheel when you want to select a reward from a prize list. If you want to do both, run each step separately and check the output rather than assuming one wheel handles both.

Does the animation change the winner?

The Duck Dash page explains that its final order is chosen before the animation begins. Review the explanation on any game you use; not every animated race uses the same method. Neither the games nor the regular wheel are a substitute for independently audited prize-draw software.

Important: SpinWheelJoy's published terms describe the tools as intended for casual games and informal use, not certified lotteries, regulated raffles, or high-stakes contests. Follow applicable laws and platform rules for promotions; use a compliant audited system if your situation requires one.
