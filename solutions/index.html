Free tools, no forced sign-up

SpinWheelJoy lets you add choices and make a random pick in your browser. Different tools support different needs. Use the Random Name Picker for a quick selection, the Team Generator to split a list into groups, or an animated race for a more visual reveal.

Currently, wheels and race games are separate experiences; a single shared Joy Session and live audience-join mode are planned features, not public functionality. Check individual tool controls before running an event.
