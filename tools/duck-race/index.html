A random draw, with a finish line. Each entry has one chance. The order is securely picked before the race; the animation reveals it. Speed, scenery and accessories do not change the result.

How this race works

This is a random name picker, not a physics-based competition. Every line is a separate entry; repeated names get extra chances. A secure shuffle fixes the final order before the countdown. The ducks then reveal that order on the river. Their racing positions before the finish are decorative. Replay shows the same race without making another draw.

Race length is the time to the first duck's finish. The remaining ducks arrive over the next three seconds. The selected podium lists these reveal times, not measured athletic times. Graphic quality never changes the draw. Browser-local storage is convenient, but this is not an independently auditable raffle platform.
