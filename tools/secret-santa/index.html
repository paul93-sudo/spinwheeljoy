How does the Secret Santa drawer work?

Enter everyone's name and tap Draw Secret Santa. The tool creates fair random pairs — nobody draws themselves, and everyone gives exactly one gift and receives exactly one gift. Then pass the device around: each person picks their own name and taps Reveal to privately see who they're buying for. Everything happens in this browser; names and pairs never leave your device.

Fairness guarantee

  • No one can draw their own name — the draw is re-rolled automatically if it happens.
  • Every participant gives one gift and receives one gift.
  • Pairs are never shown all at once and are cleared when you finish or start over.

Common questions

Can someone draw their own name?

No. The draw uses a proper derangement — if any pairing would give someone their own name, the whole draw is regenerated automatically. It can never happen.

Is the draw really private?

Yes. Names and pairs never leave this browser — there is no account, no server, and no shared link. Each person only ever sees their own recipient.

What if two people have the same name?

Add a last initial or nickname (e.g. "Anna K." and "Anna T.") so everyone can tell their entries apart.

What happens if I reload the page mid-draw?

For privacy, the pairs are kept only in memory and are cleared on reload. You'll need to draw again — it takes seconds.
