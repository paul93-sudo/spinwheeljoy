How these games work

Each game accepts a participant list, then displays an animated result. Duck Dash describes a shuffled order revealed by the race animation. Marble Rush has its own physics and progression behavior. Check each game's help panel for the exact rules; do not assume all races calculate winners identically.

Before you run a public game

Paste a short list, test the start button, verify the winner display, check replay, and confirm mute/unmute on the device being used. For informal use, display names are usually sufficient. Avoid sensitive personal data, especially on a shared projector.

Marble Rush is still undergoing device and audio QA. Its current versioned game page is intentionally withheld from Google indexing until the release is approved; the game link remains available to visitors.
